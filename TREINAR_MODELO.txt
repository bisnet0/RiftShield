  TREINAR MODELO YOLOv8 (WSL / CPU / GPU AMD)
  - Checkpoint a cada época (last.pt)
  - Melhor modelo salvo (best.pt)
  - Resume automático se parar no meio
================================================================================

1. ATIVAR VENV E TREINAR:
   source /mnt/c/Users/root_/Documents/bisnet0-GitHub/RiftShield/venv_wsl/bin/activate
   python -m backend.src.modules.inference.ml-workflow.ml_train_full

2. Se o treino cair no meio, rode de novo que ele continua de onde parou:
   source venv_wsl/bin/activate
   python -m backend.src.modules.inference.ml-workflow.ml_train_full

3. APÓS O TREINAMENTO:
   docker cp backend/src/modules/inference/train_results/best.pt riftshield-backend:/usr/src/app/src/modules/inference/train_results/best.pt
   docker restart riftshield-backend

4. (Windows) Alternativa caso o WSL não funcione:
   .venv\Scripts\Activate.ps1
   python -m backend.src.modules.inference.ml-workflow.ml_train_full
