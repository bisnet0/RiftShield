================================================================================
  ESTRATÉGIA RECOMENDADA
================================================================================

1. BAIXAR do Roboflow em formato YOLOv8 PyTorch:
   - Network topology diagram (router, switch, PC, server)
   - Class diagram detection (class, arrow)
   - Diagram detection (shapes geométricos)
   - UML diagram ML (class name, attributes, association)

2. MERGE dos datasets em um único diretório com script Python:
   - Unir arquivos train/images, train/labels, valid/images, valid/labels
   - Combinar o data.yaml com todas as classes

3. ADICIONAR as 12 imagens do Excalidraw:
   - Exportar cada tela do arquivo .excalidraw como PNG
   - Anotar manualmente os componentes (labeling via Roboflow ou LabelImg)
   - Adicionar ao dataset combinado

4. TREINAR YOLOv8 com o dataset mesclado

================================================================================
  CLASSES SUGERIDAS PARA O MODELO FINAL
================================================================================

Baseado nos componentes que aparecem em diagramas de arquitetura de software:

   Componentes de infraestrutura:
   - server / backend
   - database / banco
   - gateway / api-gateway
   - load-balancer
   - cache (redis/memcached)
   - message-queue (rabbitmq/kafka)
   - container / docker
   - storage / cdn
   - identity-provider / auth
   - microservice
   - user / client / browser

   Elementos de diagrama:
   - arrow / connector
   - cloud (internet/external)
   - rectangle / box (componente genérico)
   - label / text
